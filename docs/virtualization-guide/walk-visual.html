INTERACTIVE / FOLLOW THE PAGE-TABLE POINTERS

The address selects entries in memory

1 / 6

CR3 names the physical root of the currently active address space. The virtual address's top index selects a row in that PML4 table.

The tables are real data structures in memory, drawn with four representative rows each. A real table has 512 entries and the address bits choose an index at every level. The CPU checks permissions while following the pointers. A huge-page leaf can stop the walk earlier.
