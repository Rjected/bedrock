A guest application runs at CPL3 in VMX non-root mode. It is an ordinary process from the guest kernel’s point of view, and the host’s VMX controls still apply.

The grid is a map of authority, not a physical partition of CPU execution units. CPL and VMX mode are independent architectural properties.
